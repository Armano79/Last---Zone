# LAST ZONE — Development Roadmap

## Phase 1 — Playable prototype (included)
- 3D arena, camera, keyboard movement, mouse aiming
- Seven AI fighters, projectile combat, damage, eliminations
- Shrinking zone, match HUD, victory/defeat, replay
- Optional Supabase and Sentry integration points

## Phase 2 — Game feel (1–2 weeks estimate)
- Character animation, footsteps, weapon audio, impact effects
- Better cover navigation, spawn balancing, obstacle collision refinement
- Multiple weapons, ammunition, health pickups
- Main menu settings and pause mode

## Phase 3 — Retention (1–2 weeks estimate)
- Three maps, modifiers such as Floor Is Lava
- Authenticated player profiles and achievements
- Secure score recording and abuse protection
- Performance profiling and automated gameplay tests

## Phase 4 — Release hardening
- Accessibility and keyboard remapping
- Browser/device QA, responsive layout, analytics consent
- CI build checks, release tags, production Sentry alerts
- Security review and RLS policy hardening

## Success measures
Match start success, crash-free sessions, average match duration, completed rounds, replay rate, and performance on target hardware. All values require measurement after deployment.
